# 💧 Water Level Indicator — PCB Design

A compact and cost-effective **Water Level Indicator PCB** designed in **EasyEDA**. This project detects multiple water levels using probe sensors, NPN transistors, LEDs, and a buzzer for full-level indication. The repository includes the complete schematic, PCB layout, Gerber files, BOM, and board images.

## 📌 Project Overview

This PCB is designed to monitor the water level inside an overhead or storage tank. As the water touches each probe, the corresponding LED glows, and the buzzer activates when the tank reaches the maximum level.

### Features

- 5-level water level indication
- LED status indicators
- Buzzer alert for full tank
- Single-layer compact PCB
- EasyEDA design files included
- Ready for PCB fabrication


## 🛠️ Tools Used

- **EasyEDA** – Schematic & PCB Design
- **JLCPCB Gerber Generator** – Fabrication Files
